Positive-Unlabeled Target Formulation (Phase A1 Gate)

Because non-event dates in historical records cannot be proven to be true negative disaster absences (due to uninstrumented reporting), supervised binary classification would create synthetic bias. FloodGuard formulates spatial susceptibility under the defensible Positive-Unlabeled (PU) ML paradigm, learning relative susceptibility from validated positive inventory points without fabricating negative labels.

Evidence and unlabeled status

Strictly linked inventory evidence defines positive/unlabeled status. The current weighted binary learner encodes unlabeled observations as class 0; it does not make them verified negatives. Missing hydrology is not imputed.

02
40 Validated Village Universe

Modelling is strictly restricted to 40 validated LGD polygons with exact spatial containment (25 positive, 15 unlabeled). Unmatched areas are not interpolated.

03
Leave-One-Taluk-Out validation

Six explicit taluk holdout folds test spatial transfer. Reported metrics are positive-versus-unlabeled proxy values, not verification against known negatives or calibration.

04
Non-Destructive Scenario Engine

Rainfall scenarios evaluate in-memory feature perturbations while keeping raw data and SRTM terrain constant. Outputs are demonstration simulations, not live warnings.
